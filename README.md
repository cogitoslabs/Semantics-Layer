# Semantics Layer Pipeline

This project builds a neuroscience-specialist Small Language Model (SLM) by distilling fine-tuned Teacher LLMs on CND projection layer outputs. 

Below is an overview of the execution steps in the pipeline, including their exact configuration parameter names, default input paths, output paths, and descriptions.

## Pipeline Steps Reference

| Pipeline Step | Input(s) (Config Parameter & Default Path) | Output(s) (Config Parameter & Default Path) | Description |
| :--- | :--- | :--- | :--- |
| **s1**<br>*(Corpus Construction)* | • PDFs from local directory/cloud storage.<br>• `cfg.build.local_directory_path` (default: `.`) | • `cfg.build.output_path`<br>• **Path**: `data/dapt/domain_dapt_corpus.jsonl` | Uses the Docling parser to extract text and layout structures from PDFs in parallel using GPU workers. Splitting is done page-by-step into chunks of a configurable size. |
| **s2**<br>*(Pre-tokenization)* | • `cfg.build.output_path`<br>• **Path**: `data/dapt/domain_dapt_corpus.jsonl` | 1. **Pre-tokenized training tokens**:<br>• `cfg.data.pretokenized_bin_path`<br>• **Path**: `data/dapt/train_tokens.npy`<br>2. **Validation perplexity text**:<br>• `cfg.data.ppl_corpus_path`<br>• **Path**: `evals/dapt/ppl_held_out.txt` | Streams the JSONL corpus and splits it into training (80%) and validation (20%) sets. Tokenizes the training set using the base student model's tokenizer, and writes raw validation texts for downstream evaluation. |
| **s3**<br>*(Domain Adaptive Pretraining)* | 1. **Training tokens**:<br>• `cfg.data.pretokenized_bin_path`<br>• **Path**: `data/dapt/train_tokens.npy`<br>2. **Evaluation probes**:<br>• `cfg.data.ppl_corpus_path` (`evals/dapt/ppl_held_out.txt`)<br>• `cfg.data.qa_probe_path` (`evals/dapt/probe_qa.jsonl`)<br>• `cfg.data.vocab_cloze_path` (`evals/dapt/vocab_cloze_set.json`)<br>• `cfg.data.retrieval_prompts_path` (`evals/dapt/retrieval_prompts.json`)<br>• `cfg.data.retrieval_references_path` (`evals/dapt/retrieval_references.json`) | 1. **Model Checkpoints**:<br>• `cfg.storage.checkpoint_dir`<br>• **Path**: `models/checkpoints/`<br>2. **Evaluation metrics**:<br>• `cfg.storage.metrics_log_file`<br>• **Path**: `logs/dapt_eval_metrics.jsonl`<br>3. **Best Checkpoint Manifest**:<br>• `cfg.storage.best_checkpoint_manifest`<br>• **Path**: `logs/best_checkpoint.json`<br>4. **Risk Report (if hard-cap reached)**:<br>• `cfg.storage.risk_report_path`<br>• **Path**: `logs/dapt_hard_cap_risk_report.json` | Continues pretraining the student model on the tokenized domain-specific neuroscience corpus. Runs evaluation probes (perplexity, QA accuracy, terminology cloze, and retrieval precision) at set token intervals and applies early stopping or convergence gates. |
| **s4**<br>*(Retrieval-Augmented Distillation Prep)* | 1. **Raw reference/retrieval corpus**:<br>• `cfg.rad.retrieval_corpus_path`<br>• **Path**: `data/rad_prep/retrieval_corpus.jsonl`<br>2. **QA samples**:<br>• `cfg.rad.qa_samples_path`<br>• **Path**: `evals/dapt/probe_qa.jsonl` | 1. **Chunked reference documents**:<br>• `cfg.rad.chunks_path`<br>• **Path**: `data/rad_prep/chunks.jsonl`<br>2. **Vector Index Directory**:<br>• `cfg.rad.index_dir`<br>• **Path**: `data/rad_prep/index/`<br>3. **Grounded teacher traces**:<br>• `cfg.rad.traces_dir` / `grounded_traces.jsonl`<br>• **Path**: `data/rad_prep/traces/grounded_traces.jsonl`<br>4. **No-retrieval teacher traces**:<br>• `cfg.rad.traces_dir` / `no_retrieval_traces.jsonl`<br>• **Path**: `data/rad_prep/traces/no_retrieval_traces.jsonl`<br>5. **Logs & Phase Manifest**:<br>• `logs/rad_prep/no_retrieval_rates.jsonl`<br>• `logs/rad_prep/discarded_traces.jsonl`<br>• `logs/rad_prep/phase_manifest.json` | Chunks long-form reference documents and abstracts. Indexes them using a dense/sparse hybrid retriever. For each QA sample, retrieves context and routes to either grounded (context-supported) or no-context paths based on similarity. Queries the Teacher LLM to generate size-filtered CoT reasoning traces. Runs in three modes: `index`, `traces`, or `full`. |
| **s5**<br>*(Corpus Engineering & Micro-Clustering)* | • **Raw/parsed corpus**:<br>• `cfg.clustering.corpus_path`<br>• **Path**: `data/dapt/domain_dapt_corpus.jsonl`<br>• **PCA parameters**:<br>• `cfg.clustering.use_pca` (default: `True`) and `cfg.clustering.pca_components` (default: `10`) | 1. **Cluster assignments**:<br>• `cfg.clustering.assignments_path`<br>• **Path**: `data/clustering/cluster_assignments.jsonl`<br>2. **Three-way split dataset**:<br>• `cfg.clustering.splits_path`<br>• **Path**: `data/clustering/splits.json`<br>3. **Cluster manifest**:<br>• `cfg.clustering.cluster_manifest_path`<br>• **Path**: `data/clustering/cluster_manifest.json`<br>4. **Clustering report**:<br>• `cfg.clustering.cluster_report_path`<br>• **Path**: `logs/clustering/cluster_report.json`<br>5. **Embeddings cache**:<br>• `cfg.clustering.embeddings_cache_path`<br>• **Path**: `data/clustering/embeddings.npy`<br>6. **Document IDs cache**:<br>• `cfg.clustering.doc_ids_cache_path`<br>• **Path**: `data/clustering/doc_ids.json` | Generates document embeddings using a sentence transformer (`all-mpnet-base-v2`), applies PCA dimensionality reduction to prevent high-dimensional distance concentration, and runs HDBSCAN clustering to discover latent neuroscience domains (micro-clusters). Automatically assigns noise points to their nearest cluster, partitions the data into a three-way split (70% dev / 20% val / 10% sealed) per cluster, and logs cluster statistics. |
| **s6**<br>*(Teacher Benchmarking)* | 1. **Cluster assignments**:<br>• `cfg.clustering.assignments_path`<br>• **Path**: `data/clustering/cluster_assignments.jsonl`<br>2. **Dataset splits**:<br>• `cfg.clustering.splits_path`<br>• **Path**: `data/clustering/splits.json`<br>3. **QA samples**:<br>• `cfg.rad.qa_samples_path`<br>• **Path**: `evals/dapt/probe_qa.jsonl`<br>4. **Human labels (optional)**:<br>• `cfg.benchmarking.human_labels_path`<br>• **Path**: configured in `.env` | 1. **Teacher scores**:<br>• `cfg.benchmarking.scores_path`<br>• **Path**: `data/benchmarking/scores.jsonl`<br>2. **Benchmark manifest**:<br>• `cfg.benchmarking.manifest_path`<br>• **Path**: `data/benchmarking/benchmark_manifest.json`<br>3. **Judge calibration log**:<br>• `cfg.benchmarking.calibration_log_path`<br>• **Path**: `logs/benchmarking/judge_calibration.jsonl`<br>4. **Inter-rater agreement log**:<br>• `cfg.benchmarking.inter_rater_log_path`<br>• **Path**: `logs/benchmarking/inter_rater_agreement.json` | Benchmarks candidate teacher models across each micro-cluster. Evaluates responses on four dimensions: answer accuracy, reasoning quality (via LLM judge calibrated with Cohen's Kappa against human judges), citation accuracy, and hallucination rate (NLI model). Computes a composite score to elect the best-performing teacher model per micro-cluster. |

## Running the Pipeline

You can run individual steps or all steps sequentially using `pipeline.py`:

```bash
# Run a specific step (e.g., s1)
python pipeline.py --step s1

# Run RAD Prep (step s4) in a specific sub-mode (index, traces, or full)
python pipeline.py --step s4 --rad-mode traces

# Run all steps sequentially (s1 through s6)
python pipeline.py --step all
```
